# Licensing and data rights

The original repository has no licence declaration. This scaffold does not assign
a blanket licence to historical material or future imported datasets. Repository
metadata remains `NOASSERTION` pending owner selection and rights review.

Each source evidence record declares its known licence or `NOASSERTION`. Public
availability is not redistribution permission. Preserve manufacturer notices and
measurement partner terms; reference restricted source documents instead of
copying them. No third-party data or code is bundled by this change.
