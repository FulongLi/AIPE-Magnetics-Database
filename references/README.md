# Source acquisition and references

No manufacturer source is claimed or copied in this scaffold. Before adding one,
record its exact title/revision, stable URI or acquisition location, page/table
locator, owner, access/redistribution terms and SHA-256 of any retained artifact.
For measurements include specimen identity, operating condition, instrument and
software versions, acquisition timestamp and raw artifact. Unknown rights stay
`NOASSERTION`; inferred/derived quantities stay distinguishable from observations.
